INOVANCE PLC 工具 — 驱动安装说明
================================

本工具通过 USB 连接汇川 H5U / H6E / Easy 系列 PLC，底层依赖 libusb-win32。
请务必分清下面两层：

1. 用户态 DLL（libusb0.dll）
   —— 已内置在本工具的 exe 中（作为嵌入资源编译进 exe，含 32 位 / 64 位
      两份）。运行时按当前进程位数自动选对应那份释放到 exe 旁边，无需手动安装，
      也不依赖目标机是否提前装过 libusb。

2. 内核驱动（libusb0.sys）
   —— 这是真正与 USB 设备通信的驱动，必须由操作系统加载。
      整个驱动包（amd64/x86/ia64 三套内核驱动 + 带签名的
      H5U_USB_Device.inf / .cat）也已作为嵌入资源编译进 exe。

------------------------------------------------------------
自动安装（推荐，默认行为）
------------------------------------------------------------
本工具已内置"驱动自检 + 按需安装"：

- 每次点 RUN / STOP / 下载 时，程序先检查目标机是否装了 libusb0
  内核驱动（查注册表服务键 HKLM\...\Services\libusb0）。
- 若已安装：直接继续，不打扰你。
- 若未安装：自动从 exe 内的嵌入资源把驱动文件释放到磁盘、
  生成 install_driver.bat，并弹出 UAC 请求以管理员权限运行它
  （pnputil 安装 .inf）。安装成功后日志会提示"请重新插拔 USB 线"。

也就是说：拿到的是一个 exe，到一台没装过驱动的机器上，
第一次点任意功能就会自动完成驱动安装，无需你手动处理。

------------------------------------------------------------
手动安装（兜底场景）
------------------------------------------------------------
若自动安装被你拒绝 UAC、或企业机策略阻止，日志会提示脚本路径。
此时手动执行一次即可（任选一种）：

方法 A（命令行，最稳）：
  1. 以管理员身份打开 CMD（开始菜单搜 cmd → 右键"以管理员身份运行"）。
  2. 执行（路径换成实际释放目录，默认在 exe 旁的 INOVANCE_Drivers\）：
       Win10 / 11： pnputil /add-driver "X:\路径\INOVANCE_Drivers\H5U_usb_driver\H5U_USB_Device.inf" /install
       Win7      ： pnputil -i -a "X:\路径\INOVANCE_Drivers\H5U_usb_driver\H5U_USB_Device.inf"
  3. 看到"已成功添加驱动程序"即完成。
   （自动安装脚本已内置上述双语法自适应，无需你手动区分版本。）

方法 B（图形界面）：
  1. 进入释放目录下的 H5U_usb_driver\，右键 H5U_USB_Device.inf → "安装"。
  2. 按 UAC 弹窗确认。

驱动释放目录说明：
  - 默认释放到 exe 旁边的 INOVANCE_Drivers\（含 H5U_usb_driver\ 子目录与 install_driver.bat）。
  - 若 exe 目录不可写（如装在 Program Files 且未提权），则释放到 %TEMP%\INOVANCE_Drivers\。

------------------------------------------------------------
验证安装是否成功
------------------------------------------------------------
插上 PLC 的 USB 线，打开设备管理器 → 在"libusb-win32 devices"或
"通用串行总线设备"下，应出现 "H5U USB Device"（VID_0471 / PID_A531）。
出现后即可直接运行本工具。

------------------------------------------------------------
常见说明
------------------------------------------------------------
- 自动安装依赖 pnputil（Windows 7 / 10 / 11 均自带）。本工具内置的
  install_driver.bat 已自动适配：先试 Win7 语法 (pnputil -i -a)，失败再
  回退 Win10+ 语法 (pnputil /add-driver ... /install)，无需你手动区分系统版本。
- 本 exe 为 AnyCPU + 关闭"首选 32 位"：在 64 位 Windows 上以原生 64 位进程
  运行（加载内置的 64 位 libusb0.dll），在 32 位 Windows 上以 32 位进程运行
  （加载内置的 32 位 libusb0.dll）。两种系统下内核驱动均由 install_driver.bat
  里的 pnputil 按系统位数自动选装对应版本（amd64/x86），因此单一 exe 通用。
- 内核驱动只需在每台目标机上安装一次；之后换用不同版本的 exe 都通用。
- 若安装报错"第三方驱动被策略阻止"，多为企业机的组策略限制，
  需联系 IT 放行，或确认该驱动在本机已被信任。
- 安装完驱动后，需重新插拔 PLC 的 USB 线，系统才会重新枚举出设备。
